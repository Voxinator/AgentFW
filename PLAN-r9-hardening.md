- **HR1** CommonMark-aware fence tracking in ONE shared implementation used by every scanner (installer
  + roundtrip helpers): backtick AND tilde fences; opening run length ≥3 recorded with its character;
  a fence closes only on a line of the SAME character with run length ≥ the opening length (nothing else
  on the line except trailing spaces); up to 3 leading spaces allowed on fence lines; info strings allowed
  on the opening line; an inner shorter or other-character run does NOT close (a ````-opened fence
  containing ``` lines stays open).
- **HR2** Unclosed fence at EOF ⇒ install/upgrade/uninstall REFUSE byte-untouched (named error mentioning
  the unclosed fence), consistent with malformed-marker refusal; status warns without failing. The prior
  "everything-after-is-fenced" silent semantics are removed.
- **HR3** Marker regexes word-bounded so `<!-- AGENTFW:BEGINNING`-style lookalikes are neither treated as
  markers nor cause refusal: real markers always have a space after BEGIN/END (`<!-- AGENTFW:BEGIN r9 -->`).

  'autonomous multi-file' nor 'multi-file autonomous' survives), test runners mapped to ask not allow,
  matching settings.example.json.

  installed skill (`$SKILL_DEST/capability.yaml`); `agentfw-install status` writes

  form is gone; codex INSTALL.md adds the capability.yaml copy step.

  (A3 ⇒ independent|adversarial; A4 ⇒ adversarial), non-empty `environment`, `rerunnable` of JSON boolean
