# Export Feature API Documentation

The Export service provides functionality to extract dashboard data (tasks, events, and summaries) into various downloadable formats.

## Service Method: `export`

The `export` method handles the retrieval, filtering, and formatting of dashboard data.

### Method Signature
`async export(type: ExportType, options: ExportOptions, currentUser?: { id: string }): Promise<ExportResult>`

### Parameters

#### 1. `type` (`ExportType`)
Specifies the type of data to export.
- `'tasks'`: Exports the list of dashboard tasks.
- `'events'`: Exports the calendar events.
- `'summary'`: Exports a high-level dashboard summary (counts and timestamp).

#### 2. `options` (`ExportOptions`)
Configuration for the export process.
- `format` (`ExportFormat`): The desired output format.
    - `'csv'`
    - `'json'`
    - `'pdf'`
- `filters` (`any`, optional): Criteria to filter the exported data.
    - For `tasks`: Supports `category` filtering.
    - For `events`: Supports `dateFrom` and `dateTo` filtering.

#### 3. `currentUser` (Optional)
`{ id: string }`
Used for ownership verification to ensure the user has permission to export the requested data.

---

### Return Value (`ExportResult`)

The method returns a promise that resolves to an `ExportResult` object:

| Property | Type | Description |
| :--- | :--- | :--- |
| `data` | `Buffer \| string` | The formatted content of the export. |
| `contentType` | `string` | The MIME type (e.g., `text/csv`, `application/json`, `application/pdf`). |
| `filename` | `string` | The suggested filename for the downloaded file (e.g., `tasks_export.csv`). |

---

### Error Cases

The service throws an error in the following scenarios:
- **Unsupported Type/Format**: If a `type` or `format` is provided that is not recognized by the service.
- **Forbidden**: Thrown if the ownership verification fails (i.e., the user does not own the data they are attempting to export).

---

```typescript
const result = await exportService.export('tasks', {
```

```typescript
    dateTo: '2023-01-31' 
  }
});

```
